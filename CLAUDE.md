# Claude Experiments

This is a meta project containing multiple sub-projects.

## Project Structure

- Each folder in this directory is a separate application/sub-project
- Each sub-project has its own README.md with project-specific documentation

## Responsibilities

- Document all sub-project features in the root README.md
- Link to each sub-project's README.md from the root README.md
- Keep the root README.md updated when sub-projects are added or modified

## Git

- Always use `main` as the primary branch for this project
